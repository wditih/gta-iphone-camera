# GTA iPhone Camera 0.1.0 — экспериментальный прототип

Для GTA V **Legacy, сюжетного режима, Windows x64**. Сцены готовятся в Menyoo.
Телефон: iPhone 12 Pro Max с BlendMotion и поддерживаемой приложением версией iOS.
SteamVR, VR-шлем и Blender для этого прототипа не нужны.

**Пока не проверено в GTA и на iPhone.** Сборка и автоматические проверки не доказывают,
что камера сохранится при штатном экспорте конкретной версии игры. Сначала выполнить
короткий тест ниже, затем снимать важные сцены. Это первый прототип для проверки другом,
а не обещание готового продукта без багов.

## Как устроена съёмка

1. Создать сцену в Menyoo и обычным способом записать игровой клип для Rockstar Editor.
2. Открыть клип в именованном проекте Editor, поставить начальную свободную камеру.
3. Запустить клип и записать **отдельный проход камеры телефоном** поверх повтора сцены.
4. При просмотре и экспорте ASI подставляет сохранённое движение по времени клипа.

Камера не привязана к невидимому персонажу: положение и повороты вычисляются из ARKit.
Новая схема предполагает два прохода: сначала события сцены, затем движение камеры.
Она не записывает живую телефонную камеру во время первой записи сцены.

## Что в архиве

- `GameFiles/RockstarEditorPlus.asi` — изменённый Rockstar Editor+ с телефонной камерой.
- `GameFiles/RockstarEditorPlus/` — начальные настройки.
- `PC/PhoneCameraBridge.exe` — приём трекинга и передача превью; Python устанавливать не требуется.
- `GTA-iPhone-Camera-source.zip`, `LICENSE`, `BUILD.json` — соответствующие исходники, GPL и сведения о сборке.

Это форк [Rockstar Editor+](https://github.com/crxhvrd/REPlus), автор CoreFX.
Две версии `RockstarEditorPlus.asi` одновременно устанавливать нельзя.
Телефонная часть разработана с помощью Codex (GPT-6); ручная игровая приёмка ещё
не выполнена. Основа сохраняет лицензии и авторство REPlus, MinHook и библиотек;
описание формата BlendMotion взято из опубликованного аддона, iOS-приложение не включено.

## Установка на ПК — один раз

1. Закрыть игру. Если уже установлен Rockstar Editor+, скопировать его ASI и весь
   каталог `RockstarEditorPlus` в резервную папку вне игры. Клипам и сохранениям тоже
   нужна обычная резервная копия. Установщик здесь ничего автоматически не меняет.
2. Проверить рабочий ASI Loader для своей версии Legacy. При существующей установке
   Menyoo он обычно уже есть. [Script Hook V / ASI Loader, официальный сайт](http://www.dev-c.com/gtav/scripthookv/).
   Этот прототип не поставляет игровые файлы или загрузчик.
3. Положить `RockstarEditorPlus.asi` в папку, где находится `GTA5.exe`, рядом с другими
   ASI. Для новой установки скопировать и каталог настроек из `GameFiles`.
   Существующие пользовательские INI не заменять вслепую; достаточно нового ASI и
   `PhoneCamera.ini`. В существующем `RockstarEditorPlus.ini` нужен `Enabled=1`;
   в `Render.ini` нужен `EnableRenderer=0` для штатного Rockstar Export.
4. Оставить `PhoneCameraBridge.exe` в отдельной папке ПК. Запустить его обычным пользователем.
5. Подключить ПК и iPhone к одной частной сети Wi-Fi. В окне Bridge будут IPv4-адреса ПК.
   Выбрать адрес сетевого адаптера этой сети, обычно `192.168.*.*` или `10.*.*.*`.
6. Если Windows предлагает доступ к сети, разрешить Bridge в **частной сети**.
   Требуются входящий UDP 9090 и TCP 9091; телефон получает UDP 9091 как запасной канал.
   Проброс портов роутера и доступ из Интернета не нужны. UDP 9092 слушает только localhost.
7. Запустить GTA Legacy в оконном режиме без рамки или обычном оконном режиме.

Приложение захватывает только клиентскую область активного окна процесса `GTA5.exe`.
Если переключиться в другое окно или свернуть GTA, новое превью не отправляется.
Видимые меню Editor, курсор/оверлеи и уведомления поверх игры могут попасть в превью.
Захват эксклюзивного полноэкранного режима и HDR в этом прототипе не проверен.

## На iPhone

Используется [BlendMotion в App Store](https://apps.apple.com/us/app/blendmotion/id6760141471).
Проверить доступность, стоимость и требования iOS перед установкой или покупкой.
Цена приложения не входит в этот прототип. Нативное приложение разрабатывать/подписывать не надо.

В параметрах подключения приложения указать IPv4 ПК, UDP **9090**, превью **9091**,
если приложение предлагает отдельные поля. Разрешить камеру и доступ к локальной сети.
Включить трансляцию/preview в приложении. Экран iPhone должен оставаться активным.

Совместимость реализована по открытому Blender-аддону **v3.3.2**:
51/59-байтные `BM`-пакеты ARKit, команды `BM:`, превью `BP` и таймлайн `BF`,
UDP или WebSocket на 9091. Это проверенный формат исходников, но не проверка самого
iOS-приложения. Протокол новых prerelease 4.x может отличаться. Если Bridge не пишет
`iPhone connected`, сначала зафиксировать версию приложения и диагностику, а не
переустанавливать GTA или покупать дополнительные VR-приложения.

[Сайт/инструкция разработчика BlendMotion](https://skettchdev.github.io/BlendMotion/)
и [публичный аддон v3.3.2](https://github.com/skettchdev/BlendMotion/releases/tag/BlendMotion_3_3_2).

## Первый тест — клип на 10 секунд

1. Сохранить сцену Menyoo и записать короткий игровой клип. Открыть Editor, создать и
   **сохранить проект с окончательным именем**, добавить клип.
2. В режиме редактирования клипа поставить **Free Camera** в начальную точку вне
   персонажей и геометрии. Перемотать в начало. Не выбирать First Person или Attached.
3. Запустить Bridge, подключить BlendMotion. Вернуться в окно GTA: превью замораживается,
   пока активно окно Bridge. На телефоне должно появиться изображение игры.
4. Нажать `Ctrl+F6` в GTA для включения камеры и `Ctrl+F10` для калибровки в текущем ракурсе.
   Держать телефон спокойно. Затем повернуть вправо/влево и пройти небольшой шаг вперёд.
   Проверить направление поворота, шагов и наклона, прежде чем писать дубль.
5. На iPhone нажать запись. Байт записи в потоке BlendMotion запускает запись камеры и
   воспроизведение клипа. Запасной способ — `Ctrl+F7` в GTA. Провести 10-секундный проход.
6. Остановить запись тем же способом. Дождаться сообщения **Camera take saved**;
   в диагностике Bridge должно быть `writing: 0`, `saved` увеличится. Не закрывать
   игру, пока запись сохраняется. При остановке времени клипа больше секунды запись
   также завершается автоматически. Аварийное закрытие игры во время дубля теряет этот дубль.
7. Нажать `Ctrl+F9`, если нужен ручной выбор сохранённого воспроизведения; если Bridge
   уже показывает `playback`, режим выбран. Перемотать и просмотреть весь клип: камера
   должна повторять тот же путь. `Ctrl+F9` переключает playback/off, поэтому повторное
   нажатие в уже активном playback отключит его.
8. Закрыть и снова открыть проект, дождаться загрузки и проверить тот же проход.
   **При нескольких клипах после перезапуска открыть и просмотреть каждый клип с
   телефонной камерой до экспорта:** так все дорожки окажутся в памяти до переключений.
9. Выполнить штатный **Export** Rockstar Editor. Телефон можно отключить после
   сохранения. Сравнить начало, середину и конец экспортированного видео с просмотром.

Тест считается успешным только когда совпадают просмотр, повторное открытие проекта и
экспорт. Если просмотр верный, а экспорт отличается, это проблема интеграции экспортного
прохода; использовать длинные проекты пока нельзя. Сообщить, на каком шаге разошлось.

## Управление

| Кнопка | Действие |
|---|---|
| Ctrl+F6 | Включить/выключить живую камеру; при включении начальная точка — текущая свободная камера Editor |
| Ctrl+F7 | Начать/остановить запись камеры с текущего времени |
| Ctrl+F9 | Сохранённое движение / обычная камера Editor |
| Ctrl+F10 | Привязать телефон к текущему кадру; текущий дубль при этом завершается |
| Record в BlendMotion | Начало/конец дубля камеры |
| Recalibrate / RCAL | Перепривязать телефон к текущему кадру |
| Position Scale / Lens / FPS | Масштаб шагов / угол обзора / подписи кадров таймлайна |

Фактический FPS экспорта выбирается в Rockstar Editor. Параметр FPS телефона влияет
только на показ таймлайна; сохранённая дорожка интерполируется по игровому времени.
Seek, Retake, Focus, Reset и чувствительность поворота приложения пока не реализованы:
для перемотки/повторного дубля используются сам Editor и клавиши выше. Неподдерживаемая
команда выдаёт сообщение, а не выполняет другое действие.

ARKit может терять позицию в темноте и при резком движении. Для трекинга нужна освещённая
комната с различимыми объектами; камера iPhone должна их видеть. Экран с GTA помогает
выстраивать кадр, но сам по себе не даёт трекинг. Задержка Wi-Fi и превью остаётся;
сглаживание снижает дрожание, а не устраняет всю задержку.

После потери пакетов более 0,5 секунды дубль заканчивается и камера удерживает последний
кадр. Восстановление связи требует перепривязки; запись после разрыва автоматически
не продолжается. Если приложение всё ещё показывает запись, сначала остановить её,
затем начать новый дубль.

## Файлы камеры и ограничения первой версии

Дорожки лежат в `RockstarEditorPlus/PhoneCamera/*.pcam`, рядом — указатели `.active`.
Если каталог игры закрыт для записи, мод использует `%LOCALAPPDATA%/RockstarEditorPlus`.
Нужно копировать **всю папку PhoneCamera вместе с проектом и исходными клипами**.
Это внешние дорожки: обычный файл проекта Editor их внутрь не включает.
Предыдущие завершённые дубли сохраняются; `.active` выбирает последний.

Название проекта и исходный клип участвуют в привязке. После записи не переименовывать
проект, не менять обрезку/скорость клипа и не переставлять одинаковые копии одного клипа
без нового дубля. Перенос уникального клипа в пределах проекта предусмотрен относительным
временем, но пока не проверен в игре. Монтажные переходы, slow motion и многоклипный экспорт
требуют отдельных игровых тестов; начальный целевой сценарий — один клип, скорость 1x.

Защита от столкновений использует луч игры и небольшой отступ, это не полноценная физика
камеры. Она не исправит начальную точку внутри стены. Если функция проверки геометрии не
найдена или запрос не выполнен, перемещение удерживается с предупреждением, повороты
работают. Для диагностики можно после закрытия игры поставить `Collision=0` в
`PhoneCamera.ini`; тогда прохождение сквозь текстуры возможно по определению.

Один запуск игры после первоначальной установки ASI необходим. Переключение live/record/
playback внутри Editor реализовано клавишами без переустановки VR и без перезапуска между
дублями. Замена/удаление ASI выполняется после закрытия игры.

Для диагностики сохранить версию GTA (`GTA5.exe`), iOS/BlendMotion, режим экрана,
`RockstarEditorPlus/RockstarEditorPlus.log`, вывод Bridge и шаг короткого теста.
Для удаления закрыть игру, убрать этот ASI и восстановить резервную копию прежнего
Rockstar Editor+. Дорожки камеры сохранять до завершения монтажа.

## Что проверяется автоматически

- C++: преобразование ARKit, калибровка, сглаживание, валидация, интерполяция, чтение/запись дорожки.
- Python: реальные 51/59-байтные форматы, ограничение значений, порядок пакетов,
  потеря связи, команды, отсутствие двойного переключения записи.
- Реальные UDP/WebSocket сокеты: искусственный телефон → локальный мод,
  таймлайн/уведомление/JPEG → искусственный телефон. Синтетический кадр не захватывает рабочий стол.
- Windows CI: MSVC x64 сборка ASI и отдельного Bridge.exe.

Из этих проверок **не следует** подтверждённая работа Menyoo, iPhone, защиты от стен или
штатного экспорта GTA. Проверка на ПК друга остаётся обязательной.

## Для разработчика

Сборка: MSVC x64, CMake, Python 3.12.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --target RockstarEditorPlus phonecore_test
ctest --test-dir build -C Release --output-on-failure
python -m pip install -r bridge/requirements.txt
python -m unittest discover -s tests -p "test_*.py" -v
python -m PyInstaller --onefile --name PhoneCameraBridge --paths bridge --distpath build/bridge bridge/phone_bridge.py
python tools/package_phone.py --build build --output build/packages
```

`PhoneCameraBridge.exe --demo` передаёт синтетическое превью вместо захвата игры.
`--cutoff 0` отключает сглаживание, default 6 Гц; `--preview-fps 15` — начальный режим.
Состав сборки и отсутствие игровых проверок записаны в `BUILD.json`.
